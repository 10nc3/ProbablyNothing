CRITICAL BUGS (will crash at runtime)
1. void-pipeline.js — undefined variables t0, expertResult, sessionKey, options
    * t0 is referenced on lines 333, 354, 361, 513 but never declared. Every request will throw ReferenceError: t0 is not defined.
    * expertResult is used on line 423 (expertResult.context) but never declared. Any query that reaches the context injection block will crash.
    * sessionKey is used on lines 521, 535 but never declared. The hooks and audit logging will crash.
    * options is referenced on line 522 (options?.channel) but the destructured input uses different names.
    * Fix: Add const t0 = Date.now(); at top of runPipeline. Call getContext(query) and assign it to expertResult. Derive sessionKey from sessionId (or use hashSessionId). Map options properly.
2. test/run.js — imports DANGEROUS_PATTERNS from void-pipeline, but it's not exported
    * Line 40 destructures DANGEROUS_PATTERNS but void-pipeline doesn't export it (only exports containsDangerousPattern function). The import silently becomes undefined but if any test tries to use it, it'll fail.
3. llm-client.js — timeout lookups use dot notation on symbol keys
    * PROVIDER_TIMEOUT_MS uses computed property keys ([PROVIDERS.MINIMAX] = 'minimax'), but the axios calls use PROVIDER_TIMEOUT_MS.MINIMAX (dot notation = literal key "MINIMAX"), not PROVIDER_TIMEOUT_MS['minimax']. All timeouts resolve to undefined, meaning axios uses its default (no timeout) — providers can hang forever.
    * Fix: Use PROVIDER_TIMEOUT_MS[PROVIDERS.MINIMAX] or change the keys to literal uppercase strings.
SECURITY ISSUES
1. containsDangerousPattern only has 6 patterns — your OpenClaw blueprint blocks 33+. Missing: eval(), curl|sh, wget|bash, command substitution $(), backticks, env exfiltration (env, printenv, set), systemctl, kill, crontab, mkfs, mount, chown root, nc -l, nohup, screen, tmux, iptables, sshd, and more. Since nyanclaw doesn't have exec-watchtower, this is the only guard for prescribe mode.
2. ssrf-guard.js — missing AWS/Azure/GCP metadata IPs
    * Doesn't block 169.254.169.254 by hostname (only by IP range, which does cover it). But missing cloud-specific metadata hostnames: metadata.google.internal is there, but not 169.254.169.254 as a hostname check target, and no Azure IMDS (169.254.169.254:80 with Metadata: true header) or AWS token endpoint protection.
    * DNS rebinding: the validateURLWithDNS swallows DNS resolution errors silently (empty catch on line 99). A DNS failure should block, not allow.
3. No session memory cap — sessionMemories Map in memory-manager.js grows unbounded. The OpenClaw blueprint has a 500-session LRU cap. A burst of unique sessions could exhaust memory. The hourly TTL cleanup helps but doesn't prevent burst.
FUNCTIONAL ISSUES

Check if this test actually runs.
